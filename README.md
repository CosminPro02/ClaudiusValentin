# Transport Company Presentation Website

This project is a presentation website for a transport company, built using React.  
The website provides general information about the company, its services, and contact details.

## Features
- Company presentation
- Services section
- About us section
- Contact information
- Responsive design

## Technologies
- React
- JavaScript

## How to run the project
1. Install dependencies:
   npm install
2. Start the development server:
   npm start
3. Open the browser at:
   http://localhost:3000
